# Data Sources

The calibration target file records the source, series identifier, transformation, units, geography, and anchor period for each moment. Raw public series retained in `data/empirical/raw` include labor market, output, debt, earnings, prices, inequality, firm exit, equity market, and corporate spread data.

The AI adoption anchor is a documented public estimate rather than a direct extract from confidential microdata. Forward looking scenario parameters and emerging operational risk channels are disclosed assumptions rather than historical estimates.

Users should review the original provider terms before redistributing raw data. Derived targets and transformations are documented in `data/calibration_targets.csv` and `data/empirical/empirical_data_sources.md`.
