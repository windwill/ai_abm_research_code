# `abm_ai` Package

The package is organized around four core files: `parameters.py` defines the settings, `agents.py` defines the actors, `simulation.py` coordinates their interactions, and `moments.py` summarizes the resulting path. `config.py` and `scenarios.py` provide the main input interfaces.

For a module-by-module map, execution flow, Python example, and extension guidance, see `../../docs/SOURCE_CODE_GUIDE.md`.
